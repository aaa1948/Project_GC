# 기본 침 자동 조준 / 유도침 곡선 추적

## 확정 동작

- 기본 침은 발사 시 사거리 안의 가까운 공격 가능 몬스터를 조준한다. 발사 후에는 직진하며 재조준하지 않는다.
- 표적이 없으면 마지막 자동 조준 방향을 유지한다. 캐릭터 이동, 대쉬, 액티브 스킬 방향은 변경하지 않는다.
- 필드를 한 번 클릭하거나 터치하면 다음 **한 발**의 발사 방향만 지정한다. 추가 투사체는 자동 조준과 기존 부채꼴 분산을 적용한다. 발사 간격과 피해량은 유지한다.
- UI 버튼, 조이스틱, 일시정지 화면의 입력은 방향 지정을 하지 않는다. 아이템 추가 발사는 예약한 한 발을 소비하지 않으며, 이기어침·산탄·대물침의 수동 조작은 유지한다.
- 유도침은 **발사 직후부터** 비행 중 적을 향해 부드럽게 회전한다. 표적이 유효한 동안 유지하고 죽거나 탐지 범위 밖으로 나가면 재탐색한다. 사거리 끝에서 추적을 시작하는 안은 폐기했다.

## 거리와 강화

실제 스테이지 1 아시 대기 스프라이트의 가로 크기는 약 0.82037 월드 단위(443px / 675 PPU × 씬 비주얼 배율 1.25)다.

| 항목 | 기본값 | 기준 |
| --- | ---: | --- |
| 침 최대 비행 거리 | 4.1 | 아시 약 5개 길이 |
| 유도침 탐지 반경 | 4.92 | 아시 약 6개 길이, 비행 중 침 위치 기준 |

- 사거리 강화는 최대 비행 거리에 적용된다. 비행 거리는 곡선 궤적을 따라 누적하며, 유도침이라고 무한히 날아가거나 추가 거리를 얻지 않는다.
- 기존 `추적 시야`는 탐지 범위 +14%, `유도 선회`는 회전 반응 속도 +6%, `추적 정밀도`는 유도 대상 적중 피해 +8%를 유지한다. 탐지 강화와 비행 사거리 강화는 별도다.
- 일반 침의 사거리 끝 소멸 효과와 침귀환의 기존 귀환 분기는 유지한다.
- 특수 증강의 한국어/영어 설명, 튜토리얼, 오리지널 설명, 탐험 기록의 기본 침 설명을 갱신했다.

## 검증

Unity 2022.3.62f3의 실제 스테이지 1 씬에서 `Vampire.Tests.Editor.NeedleAimSmoke.Run`을 실행한다.
검증 대상은 아시 실제 크기와 거리 강화, 표적 유효성, 실제 다중 발사 중 수동 방향 1회 소비, 아이템 추가 발사의 예약 보존, 마우스 누름/유지, UI 터치 제외, 다른 손가락을 누른 상태의 필드 터치, 정지 중 입력 제거, 기본침 직진, 움직이는 표적에 대한 즉시 곡선 추적, 탐지 범위 이탈, 정확한 거리 종료, 기존 소멸 파티클이다.

로그: `Library/NeedleAimSmoke.log`, 결과: `Library/NeedleAimProof/result.txt`.
실기기 모바일 QA 및 공유 링크 빌드/배포는 이번 변경에 포함하지 않는다.
