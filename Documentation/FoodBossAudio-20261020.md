# 보스 효과음 선택본 적용 — 2026-10-20

사용자가 마지막에 전달받은 57개 개별 효과음을 게임에 적용한다. 이후 요청된 탕후루파 충전·발사 및 우동커튼 수정본을 포함한다. 이전 합성 제작본으로 재생성하지 않는다.

## 보스별 연결

| 보스 | 소리 테마와 연결 |
|---|---|
| 롤팽이 | 부드러운 크림 탄막·롤링·나선·토핑, 회복 준비와 미니 롤 흡입을 별도 소리로 분리 |
| 데니카니 | 구운 껍질과 집게의 단단한 접촉, 집게 뻗기·충격파·급정거 휩쓸기 |
| 마리비 | 마들렌 클릭과 레몬즙, 기관총·실제 분사·2페이즈 착지 분출 |
| 탕뎅이 | 확정 날개 대쉬 그대로 유지. 충전음과 빔 발사음 분리, 설탕 파편·실·스키딩은 별도 소리 |
| 후루미 | 확정 촉촉한 면발 타격음 그대로 유지. 최신 우동커튼, 면발 점프·착지·초밥 회복 |

공통 11종 × 5보스 + 롤팽이 Consume + 탕뎅이 Beam = 57개.
일부 공통 예비 슬롯(Skid 등)은 해당 동작이 없는 보스에서는 재생되지 않는다.

## 재생과 동기화

- 재생 pitch=1. 선택 원본을 변조하거나 재정규화하지 않는다.
- 탕뎅이 날개음은 돌진 준비부터 시작하고 돌진 종료 후 감쇠한다.
- 탕후루파 충전 경고는 원음 길이에 맞춰 약 1.88초. 이후 빔 발사음을 재생한다.
- 우동커튼 빈칸 전환 시 이전 소리를 0.08초 감쇠시켜 겹쳐 쌓이는 것을 방지한다. 패턴 종료 시에도 감쇠한다.
- 레몬즙·면발 채찍·집게 뻗기 등은 실제 동작 시점에 재생한다.
- 효과음 설정, 거리 감쇠, 화면 좌우 위치를 반영한다. 탄막·파편이 주요 돌진/빔을 밀어내지 않도록 6개 채널에 우선순위를 적용한다.
- 일시정지 시 재생 및 감쇠를 멈추고, 패턴 취소/보스 비활성화 시 정리한다.

## 선택 파일 보존 및 검증

`Tools/Audio/selected-manifest.json`은 57개 이름·라벨·해시·신호 측정값의 기준이다.
`Tools/Audio/Approved`의 기존 테마 원음은 보관용이다. 실제 게임 파일은 `Assets/Resources/FoodBosses/Audio`이다.
특히 `3-Dash.wav`, `4-Skill2.wav`는 확정 마스터와 바이트 단위로 동일하다.
출처와 CC0 기록은 `Tools/Audio/CREDITS.txt`에 보관한다.

```text
python Tools/Audio/build_food_boss_audio.py
python Tools/Audio/build_food_boss_audio.py --source <선택 패키지 폴더>
```

인수 없이 실행하면 현재 파일을 검증한다. --source는 57개 구성, 해시, PCM 및 확정 원음을 먼저 검사한 뒤 그대로 복사한다. 합성·재필터링 기능은 없다.
Unity 검증 진입점은 `FoodBossAudioSmoke.Run`이다. 빈 테스트 씬에서 5개 보스의 실제 AudioSource와 Resources 로딩, 디코딩된 PCM, 57개 재생 및 재생 시계 진행을 검사하며 게임 씬이나 저장된 설정을 변경하지 않는다.

## 적용 검증 결과

- Unity 2022.3.62f3 컴파일 및 오디오 임포트 완료.
- 일반 Editor Play Mode에서 57/57 파일의 로드, 비어 있지 않은 디코딩 PCM, AudioSource 재생 및 timeSamples 증가 확인. `FOOD_AUDIO_SMOKE_PASS clips=57`.
- 테스트에서만 짧은 클립을 반복 재생하여 에디터 프레임 지연에 따른 오판을 방지하며, 실제 게임 소리는 기존처럼 1회 재생한다.
- 이 환경의 batchmode에서는 오디오 시계가 진행되지 않아 일반 Editor 모드로 검증했다.
- 실제 스피커로 전 패턴을 청취한 검수는 아니다. 사운드 내용은 사용자가 선택한 파일을 그대로 사용했다.
- 기존 이미지 메타데이터·폰트·프로젝트 설정 변경은 이 커밋에 포함하지 않는다.
